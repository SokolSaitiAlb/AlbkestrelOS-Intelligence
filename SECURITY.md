# Security Policy

## Reporting a vulnerability

Do not disclose exploitable vulnerabilities in public issues. Use GitHub's private vulnerability reporting feature if enabled for this repository, or contact the repository maintainer through a private channel.

## Scope

Security-sensitive areas include:
- model loading and package verification;
- permission broker and policy engine;
- action execution adapters;
- local memory and encryption;
- IPC and Binder/AIDL boundaries;
- SELinux and privileged integration;
- data-provider integrations and audit logs.

## Expectations

Reports should include affected version/commit, impact, reproduction steps, and any relevant logs with personal data removed. Do not include credentials, private prompts, health records, or other sensitive user data.
